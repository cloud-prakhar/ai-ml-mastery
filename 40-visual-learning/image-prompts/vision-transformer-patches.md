# Image prompt — Vision Transformer Patches

**Purpose:** show an image cut into patches that become a sequence of tokens, like words in a sentence
**Audience:** 🟡 intermediate
**Aspect ratio:** 16:9 (documentation) / 9:16 (learning card)
**Teaches:** [09 Computer Vision — Detectors, Vision Transformers, SAM and CLIP](../../09-computer-vision/06-detectors-vit-sam-and-clip.md)

## Prompt

A friendly, modern, flat-illustration diagram explaining how a vision transformer reads an image.
Style: clean vector, high contrast, generous whitespace, rounded shapes,
soft shadows, educational infographic aesthetic, minimal text.
Palette: blue #2563eb, amber #d97706, purple #a21caf, green #059669 on a light background.
Show: on the left, a simple illustration of a house cut into a 4-by-4 grid of square tiles with thin gaps. In the
centre, the tiles lined up in a single row like dominoes, each with a small numbered position tag, and one extra
purple tile at the front. On the right, a blue box with curved lines connecting every tile to every other tile,
and a green output card. Connect the three parts with clear arrows. Label each element with two or three words maximum.
No photorealism. No clutter. No small print. No fake logos or brand marks.

## Text overlay (keep it this short)
- Title: Patches as Words
- Labels: "Cut into patches", "Tokens + position", "Class token", "Attention"

## Accuracy checks before use
- [ ] Every tile has a position tag — position is added, not implied
- [ ] The extra class token is at the front of the row
- [ ] Any text in the image is spelled correctly
- [ ] Nothing implies endorsement by a real company
