# Image prompt — Convolution and Feature Maps

**Purpose:** show a small filter sliding over an image and producing a feature map that lights up where its pattern appears
**Audience:** 🟢 beginner
**Aspect ratio:** 16:9 (documentation) / 9:16 (learning card)
**Teaches:** [09 Computer Vision — Convolution, Pooling and Augmentation](../../09-computer-vision/02-convolution-pooling-and-augmentation.md)

## Prompt

A friendly, modern, flat-illustration diagram explaining convolution in a neural network.
Style: clean vector, high contrast, generous whitespace, rounded shapes,
soft shadows, educational infographic aesthetic, minimal text.
Palette: blue #2563eb, amber #d97706, purple #a21caf, green #059669 on a light background.
Show: on the left, a simple grid image split into a dark half and a bright half; a small 3-by-3 amber
window sitting on the boundary between them, with a dotted path showing it sliding row by row. In the centre,
the 3-by-3 window enlarged with a multiply sign and a sum sign. On the right, a smaller grid (the feature map)
that is dark everywhere except a bright green vertical stripe exactly where the boundary was.
Connect left to centre to right with clear arrows. Label each element with two or three words maximum.
No photorealism. No clutter. No small print. No fake logos or brand marks.

## Text overlay (keep it this short)

- [ ] The feature map is smaller than the image (no padding shown) and bright only at the edge
- [ ] The filter is shown at one position, with its path, not as several different filters
- [ ] Arrows point from image to feature map
- [ ] Any text in the image is spelled correctly
