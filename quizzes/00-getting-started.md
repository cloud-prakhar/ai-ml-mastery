# Quiz — 00 Getting Started

**Level:** 🟢 Beginner

Attempt every question before opening the answers.
Answers with reasoning: [`answers/00-getting-started.md`](answers/00-getting-started.md)

---

## Beginner questions

1. What does the `pwd` command tell you?
2. What does the `(.venv)` prefix in your terminal prompt mean?
3. Which command lists the packages installed in your current environment?
4. What is the difference between Git and GitHub?
5. Why should the `.venv/` folder never be committed to Git?

## Conceptual questions

6. Explain what a virtual environment is to someone who has never programmed, using an analogy.
7. Why does `pip install` sometimes need to be run as `python3 -m pip install` instead?
8. What is the difference between a virtual environment and a Docker container?
9. Why is "Restart Kernel and Run All Cells" essential before sharing a notebook?
10. Why pin exact versions in `requirements.txt` instead of listing bare package names?

## Practical questions

11. You installed pandas but Python says it is missing. List three things to check, in order.
12. How do you make Jupyter use a specific virtual environment?
13. How do you recreate a colleague's environment exactly from their repository?
14. How do you check which Python executable is currently active?
15. You accidentally committed an API key to a public repository. What is your first action?

## Scenario questions

16. A teammate says "it works on my machine". What do you ask them for, and why?
17. You are on a laptop with no GPU and a module requires one. What do you do?
18. Your `pip install` fails with a compiler error on Windows. Name two different fixes.
19. You need PyTorch 2.0 for one project and 2.5 for another, on the same machine. How?
20. A notebook produces different results every time it runs. Name two likely causes.

## Interview questions

21. "How do you ensure your machine-learning work is reproducible?"
22. "Walk me through how you would onboard a new team member to an existing Python project."
23. "What is the difference between `pip freeze` and a hand-written requirements file, and when
    would you prefer each?"
24. "How do you handle secrets in a data-science project?"
25. "Why do so many machine-learning teams containerise their work?"
