# Advanced Projects

Projects in this tier are catalogued in
[`PROJECT_CATALOG.md`](../../PROJECT_CATALOG.md#), with the modules each one requires and what it teaches.

**Status:** none built yet. See [`IMPLEMENTATION_TRACKER.md`](../../IMPLEMENTATION_TRACKER.md).

Each project lives in its own folder here and follows
[`templates/PROJECT_TEMPLATE.md`](../../templates/PROJECT_TEMPLATE.md) — which means it ships with
a problem statement, architecture diagram, dataset details, runnable code, tests, security notes,
monitoring notes, cost notes, troubleshooting, extension challenges and interview discussion points.

A project that lacks the testing, security and cost sections is a script, not a project, and will
not be merged.
