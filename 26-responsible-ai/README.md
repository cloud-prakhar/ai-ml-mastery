# 26. Responsible AI and AI Ethics

**Level:** 🟡 Intermediate &nbsp;|&nbsp; **Effort:** Detailed module &nbsp;|&nbsp; **Status:** 📋 Backlog

Bias, fairness, transparency, privacy and governance - with measurable fairness metrics rather than slogans.

---

## 🎯 Learning Objectives

By the end of this module you will be able to:

- Measure group fairness with named metrics on a real dataset.
- Write a model card and a datasheet for a model you built.
- Identify where human oversight must sit in a given system.
